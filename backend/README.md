
# API для игры Wordle

Этот API предоставляет функциональность для игры, в которой пользователи пытаются угадать слово. Он включает маршруты для начала игры, получения ежедневного слова, отправки попыток и получения результатов. API разработан с использованием Flask и SQLAlchemy.

## Основные маршруты

### 1. **Получение ежедневного слова**  
**URL**: `/game/daily`  
**Метод**: `GET`  

#### Параметры запроса:
- `user_id` (обязательный): ID пользователя, который запрашивает ежедневное слово.

#### Описание:
Этот маршрут возвращает слово, которое является ежедневным (флаг `daily=True`). Если пользователь уже играл с этим словом или у него есть активная сессия с этим словом, API вернет ошибку.

#### Пример запроса:
```
GET /game/daily?user_id=1
```

#### Пример ответа:
```json
{
  "game_id": 1,
  "word_length": 5,
  "attempts_left": 6
}
```

---

### 2. **Получение случайного слова для игры**  
**URL**: `/game/start`  
**Метод**: `GET`  

#### Параметры запроса:
- `user_id` (обязательный): ID пользователя, который запрашивает случайное слово.

#### Описание:
Этот маршрут создает новую игру с случайным словом из базы данных. Если у пользователя уже есть незавершенная сессия, она будет удалена перед началом новой игры.

#### Пример запроса:
```
GET /game/start?user_id=1
```

#### Пример ответа:
```json
{
  "game_id": 1,
  "word_length": 5,
  "attempts_left": 6
}
```

---

### 3. **Попытка угадать слово**  
**URL**: `/game/guess`  
**Метод**: `POST`  

#### Тело запроса:
```json
{
  "game_id": 1,
  "guess": "apple"
}
```

- `game_id` (обязательный): ID игры, для которой отправляется попытка.
- `guess` (обязательный): Предположенное слово.

#### Описание:
Этот маршрут обрабатывает попытку угадать слово в игре. Ответ возвращает информацию о правильных и неправильных буквах в предложенном слове. Также обновляется количество оставшихся попыток и статус игры (выиграл или проиграл).

#### Пример запроса:
```json
{
  "game_id": 1,
  "guess": "apple"
}
```

#### Пример ответа (если угадано правильно):
```json
{
  "result": "win",
  "feedback": ["correct", "correct", "correct", "correct", "correct"],
  "attempts_used": 6
}
```

#### Пример ответа (если не угадано):
```json
{
  "result": "incorrect",
  "attempts_left": 5,
  "feedback": ["correct", "present", "absent", "absent", "absent"]
}
```

#### Пример ответа (если проиграно):
```json
{
  "result": "lose",
  "correct_word": "apple",
  "feedback": ["correct", "absent", "absent", "absent", "absent"]
}
```

---

## Ошибки

- **400 Bad Request** — Если параметры запроса или данные невалидны (например, неверная длина слова или уже завершенная сессия).
- **404 Not Found** — Если не найдено слово или игра.
- **500 Internal Server Error** — Если произошла ошибка на сервере.

---

## Пример работы с API

1. **Получение ежедневного слова**:
   - Запросите ежедневное слово с помощью параметра `user_id`.
   - Если игрок уже играл с этим словом или есть активная сессия, получите соответствующую ошибку.

2. **Начало игры с случайным словом**:
   - Получите случайное слово с помощью параметра `user_id`.
   - Если у пользователя уже есть активная сессия, она будет удалена.

3. **Попытка угадать слово**:
   - Отправьте предположение (слово) и ID игры.
   - Получите информацию о том, насколько угаданы буквы, и обновите количество оставшихся попыток.

---

Этот API предназначен для использования в клиентской части игры Wordle. Он позволяет пользователю начать игру, получить ежедневное слово и отправлять попытки для угадывания слова.
